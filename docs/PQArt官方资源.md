## 使用说明

1. 官网的「学Art」栏目就是官方文档入口，《PQArt 使用手册》是站内电子书；部分课程与下载内容需要登录账号。
2. 回答里引用官网信息时给出完整链接，便于用户自己复核。
3. 本机知识库之外的公开信息（版本发布说明、教程、常见问题）可以联网检索后再回答；
   检索不到就直说没有找到，不要编造链接或版本号。
4. 官方域名之外的镜像站（如 `pqart.cn`、`robotart.com`）未核实是否官方，引用前先确认可访问。

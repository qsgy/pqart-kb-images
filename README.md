# PQArt knowledge base images

Public image assets referenced by the PQArt DingTalk assistant knowledge base.
Sources: PQArt operation tutorials and the PQArt/PQCAM installation guide.

- v2/: real JPEG/PNG files used by the knowledge base. Use this directory.
- Root: original exports from the internal knowledge base. The .jpg files there are ZIP wrappers produced by MaxKB large-object export; they are kept for traceability and are not directly usable as images.

The 12 tutorial screenshots were exported from MaxKB and unwrapped into v2/. The 3 installation screenshots come from the PQArt skill references.
